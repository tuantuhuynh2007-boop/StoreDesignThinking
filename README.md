# StoreDesignThinking

Dự án Tư duy Thiết kế (Design Thinking) cho cửa hàng.

## Giới thiệu

Repo này lưu trữ tài liệu và mã nguồn liên quan đến quá trình áp dụng phương pháp **Design Thinking** vào thiết kế cửa hàng.

## Các giai đoạn Design Thinking

1. **Empathize** - Thấu hiểu người dùng
2. **Define** - Xác định vấn đề
3. **Ideate** - Lên ý tưởng
4. **Prototype** - Tạo nguyên mẫu
5. **Test** - Kiểm thử
